## Method and confidence

- API rows: every row was matched to a live route from the OpenAPI schema of create_app() (330 routes), the handler or player-action function was located, the frontend caller was found with scripts/audit_api_usage.py logic, and a backend test was looked for at route level or at the action-handler level (tests/services/player, tests/api, tests/engine). Legacy paths that moved (kitap, yedek, gorsel) were mapped to /api/book, /api/backups/{file}/database|package and /api/media/{file}. Only API-032 (reputation nudge cap and dead-son refusal) was compared line by line with the legacy function (src/itibar.js:itibarIt) and matches it. Other API rows are thin aliases over the player action catalogue (backend/src/aerona/services/player/catalog.py); their behavioural fidelity belongs to the TOOL, DEEP and INT audits.
- UI rows: the planned module names in the matrix mostly no longer exist (the frontend followed the shadcn-admin layout: sidebar pages instead of a header and drawers). Each row was mapped to the real component (evidence column), checked for reachability from frontend/src/main.tsx through an import graph (only features/images/ImageQueueFeed.tsx is unreachable), and probed with targeted code searches for the distinctive behaviour. This is component-level verification, not a line-by-line comparison with the legacy views. Tests counted: 39 vitest files and 4 playwright specs; the playwright consistency spec only checks layout rules on every screen and is not counted as exercising behaviour.
- The matrix Status and Test columns were ignored as instructed.

## Ten most serious gaps

1. UI-028, UI-029, UI-031, UI-005, UI-465: the live agent stream (streamed thoughts, tool calls with targets and excerpts, long-write counters, grouped reading tools, tool icons) does not exist. backend/src/aerona/events/kinds.py has no tool or thought event and the feed (frontend/src/features/feed/feedModel.ts) only renders job, epoch, turn start and finish, engine, Fate and record events. Decision 10 permits dropping dead kinds, but spec 12 section 5 defines emitters for these, so the player cannot watch a son think. Scope L.
2. UI-166: nothing cites the World Rule that controls a displayed number (no RuleRef equivalent), which breaks the architecture rule that every number is traceable to a rule. Scope L.
3. API-180 and UI-018: GET /api/events sends no hello event carrying the busy state and has no backend test of resume, ping or ordering (backend/src/aerona/api/routers/events.py:32). Scope M.
4. UI-167 and UI-168: no idle-gated refresh and no incremental change patching; GET /api/changes feeds only the overview digest and SSE invalidation replaces the legacy patch pipeline. Open question for decision 13. Scope M.
5. API-047, API-084, API-086, API-077, API-101, API-102, API-113: god-power and cosmic player actions (strip power, manifest, convert, order rite, drain and kill foreign god, recall voyage) have routes and UI but no test that runs the handler. Scope S each.
6. UI-213 to UI-221: the global header with the essence counter, doom clock bands, mood chip, star and climate chips, summon and revelation buttons with cost chips and the prayers badge was folded into the Overview summary card; the essence breakdown popover, doom bands and header-level summon are gone. Scope M.
7. UI-270: foreign-god bonds are read-only although the matrix marks create and break controls as needed (frontend/src/features/foreign-god/ForeignGodRelations.tsx). Scope M.
8. UI-224: Settings Appearance has no reduce-motion, text-size or contrast control; only theme, font and sidebar options. Scope M.
9. UI-023: features/images/ImageQueueFeed.tsx is never mounted and image queue lines in the feed carry no thumbnail or progress line. Scope S.
10. About 350 UI rows have no test at all: the unit tests cover models only (feed, chronicle, graph, atlas, map viewport, rules, wizard, registry) and the e2e specs cover the map, network and 2D cosmos; screens such as the pantheon, creator, entity page, gallery, languages, notifications, ledger, settings and the 3D cosmos have no behavioural test. Scope L overall.
