- Every row was mapped to its live module (planned paths moved: agents/fate.py is agents/fate/, services/canon_facts.py is engine/primitives/canon_facts.py, llm/structured.py is merged into llm/client.py, catalog files were renamed). - Frontend callers: 317 of 330 routes have a caller by scripts/audit_api_usage.py; the 13 it lists are mostly false negatives from quoting style and were checked individually.

## Cross-cutting findings

- Metrics never get an epoch: agents/metrics.py defines ContextVars current_epoch and current_actions but nothing sets them (metrics_epoch has no caller). Every llm_calls row has epoch NULL and actions NULL, so per-epoch metrics are empty and metrics pruning (which keys on max epoch) never deletes (LLM-020, SVC-036, SVC-037, SVC-038, SVC-200, SVC-214).
- Live log and bus: the event bus is an in-memory ring. MetricsService.record_event, the LiveEventRow table and the rules epoch_flow.live_log_db/live_log_memory exist but are never called, so the persistent live log, its reload at startup and epoch stamping are missing (EPOCH-005, EPOCH-006, EPOCH-008).
- Notifications: NotificationService.epoch_finished and agent_error have no callers, so epoch-finished and son-targeted error notifications are never produced (EPOCH-007).
- Historical map: services/wiki.py:take_snapshot is only called from a test; map_snapshots is never written, so the time slider reads an empty table (SVC-123, SVC-124, SVC-182).
- Prompt preview surfaces: 27 CTX rows plus LLM-021, LLM-022, LLM-045 and CORE-054..059 demand preview or viewer surfaces (GET /api/prompt-context/*, prompt catalogue, son prompt preview, tired motifs list). None of these routes or frontend features exist, although all builders are real and wired.
- Maintenance and on-demand repairs: there is no Settings > Maintenance panel or endpoint. All startup and epoch-end repairs run automatically only (SVC-199..208, SVC-213, EPOCH-036, CORE-020/021/060/066/071/072). Startup completion has no manual job endpoint (LLM-026, EPOCH-016, EPOCH-049).
- LLM streaming: no writing-progress events, no agent transcript events, no structured-call retry notifications, no test-only abort hook (LLM-004, LLM-005, LLM-007, LLM-011, LLM-013). Only turn-level restarts and continuations are published.
- Fate manual controls: no re-judge of Fate debt or limbo, no verdict override, no retry of Fate, voices or sensed-world births (LLM-060, LLM-061, LLM-063, EPOCH-031, EPOCH-032, EPOCH-037, LLM-098, LLM-099, LLM-100).
- Decision 22 gap: the rejection rollback in agents/fate/judge.py:run_fate runs in a second write transaction after the verdict transaction (LLM-077, LLM-078).
- Dead twins: services/canon.py:CanonCache (built, never used by the engine), services/threads.py advance/close/liveness, services/empty_worlds.py, services/integrity/mortal_age.py, services/gods/* run_* functions, services/bonds.py close_bond/hand_over_contents, agents/context/fragments.lore_language_directive. Live behaviour sits elsewhere (agents/fate/apply.py, engine/gods/opportunities.py, services/integrity/age_consistency.py, db repositories), so these are code-duplication and drift risks, and CanonCache is a real wiring gap (CORE-005, CORE-006, CORE-007).
- Unread rules: 49 of 3588 declared rule keys have no reader (for example context.fate_*_chars and context.son_*_chars, epoch_flow.live_log_db, reputation.manual_*_click, world_birth.region_*, agents.auto_*), against decisions 24, 32 and 55 (NEW-010, NEW-011).
- Database constraints: no unique index for one active inside bond per entity or for one bond per unordered pair of a singular narrative type; the state-bond index is directional (INV-005, INV-006, INV-010).
- Untested live paths: epoch-end background work (auto-deepen, stale epics, foreign-god deepening), deferred sensed-world births, startup completion hook, image auto-generation (EPOCH-016, EPOCH-037, EPOCH-041..046, SVC-116, SVC-117).
