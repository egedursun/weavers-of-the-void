## Cross-cutting findings

- Map cache invalidation is region-set only (MAP-027, MAP-030, MAP-026): new settlements and other markers get no map position until a region appears or the creator runs world:map; world edits and exile do not invalidate.
- Water regions cannot exist in a live game (MAP-016): is_water has no writer in birth, creation tools, record:edit or the drawer.
- Language voice in the live path ignores ancestors, dialect sample names and signature inheritance/persistence (LANG-003, 004, 005, 007, 008, 009); only unit tests exercise those pieces.
- Words of the epoch pick records by id instead of power and use the first language of the world instead of the local language (LANG-020, LANG-022).
- Friendly first contact on arrival never triggers the two-way culture exchange (TRV-039); cultural_contact(first_contact=True) has no live caller.
- Cosmic travel resource is not defined at genesis, contrary to decision 51 (COS-011).
- Sub-engine phases cannot be run on demand from any API or UI (TRV-018, EXP-020, PAN-003, BEY-029); they can only be disabled through rules.
- Planet worship conversion runs outside the per-world act roll (BEY-009); soul descent reach differs from legacy and is not in decisions.md (BEY-004).
- Creator controls missing for extinguishing a star and for forcing or forbidding a son's outer bargain (PAN-022, PAN-023).
- No creator control for language script, signature, seed or terrain overrides (LANG-007, LANG-019, MAP-001, MAP-002), and no fog toggle (MAP-020) or geography preview (MAP-031).
- Road-event LOST_WAY lengthens the journey by one epoch, absent from legacy and decisions.md (TRV-025).
