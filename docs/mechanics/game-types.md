# Weavers of the Void®: Every Type in the Game

The engine works with typed things: every kind, state, cause, role and outcome it can tell apart is a fixed list of values. This booklet counts every one of those lists and names every value in it, read straight from the game's code. The open catalogues come first: their kinds ship with the game and you can add more of your own.
