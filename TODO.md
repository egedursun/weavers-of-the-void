The primary goal is to make sure every interconnected functionality and mechanic is performing their duties in a balanced and intuitive way. The second goal is to make sure these dynamics work correctly and not missing any interconnections within each other and fully connected like a real world simulation. The third goal is to make sure the game engine in terms of performance in time management is fully optimized and does not take an unintuitively long time. All of these steps must be done to ensure the simulation / generator is fully compliant and ready for the real world and practical use as a production grade application.
