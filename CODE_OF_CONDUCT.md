# Code of Conduct

Weavers of the Void is made by people who build worlds together. This code describes how we treat each other in every project space: issues, pull requests, discussions, chat and events.

## What we expect

- Be respectful and considerate, especially when you disagree.
- Give and accept feedback about work, not about the person.
- Assume good faith, and ask when something is unclear.
- Make room for newcomers and for people whose first language is not English.
- Respect people's privacy and boundaries.

## What is not acceptable

- Harassment, intimidation, threats or personal attacks.
- Insults or demeaning remarks about anyone's identity, background, body, ability, age, gender, sexual orientation, religion or nationality.
- Sexual language or attention that is unwelcome.
- Publishing someone's private information without their permission.
- Repeatedly disrupting discussions, or pushing on after being asked to stop.

The worlds made with the software can contain any kind of story. This code is about how people treat people in the project, not about the fiction itself.

## Reporting

If you experience or witness behaviour that breaks this code, contact a maintainer privately (see [MAINTAINERS.md](MAINTAINERS.md)). Reports are handled confidentially. If a report concerns a maintainer, contact the project owner, or another maintainer if the report concerns the owner.

## What happens

The maintainers review every report and decide on a response that fits what happened: a private word, a public warning, a temporary ban or a permanent ban from the project's spaces. The person reported is heard before a decision, unless that would put someone at risk.

## Scope

This code applies in every project space and when someone represents the project in public.
